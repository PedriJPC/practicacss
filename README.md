# Práctica CSS - PedriJPC
### 1. Bloque vs En línea: Bloque ocupa todo el ancho; en línea solo su contenido.
### 2. Class vs ID: ID es único (#); Class se repite (.).
### 3. Margin vs Padding: Padding es espacio interno; margin es externo.
### 4. box-sizing: border-box: Hace que el ancho incluya padding y borde.
